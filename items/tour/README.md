# Onboarding tours

`/tour [what]` has the agent write a guided tour of the repo (or the service or feature you name) for a new teammate: 8–20 stops in reading order, each a real file and line with why it matters, following one real request end to end. It's saved as a [CodeTour](https://github.com/microsoft/codetour) in `.tours/` (step through it in VS Code) and as a markdown page.
